# Slice 09 — Explainability and Demo

## Module
`evaluate` / `app`

## What to build
Generate permutation feature importance and a lightweight Streamlit demonstration.

## Acceptance criteria
- [ ] Top feature importances are generated for the selected model.
- [ ] Demo loads the trained pipeline/model.
- [ ] Demo displays a risk probability.
- [ ] Demo displays the classification using the frozen threshold.
- [ ] A reproducible test applicant/example can be demonstrated.

## Out of scope
Complex frontend and cloud deployment.
