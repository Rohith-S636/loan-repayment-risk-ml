# Slice 09 — Explainability and Demo

## Module
`evaluate` / `app`

## What to build
Generate permutation feature importance for the final accepted model and build a lightweight, polished Streamlit demonstration.

## Acceptance criteria
- [ ] Top feature importances are generated for the final selected model.
- [ ] Demo loads the final trained model and preprocessing pipeline.
- [ ] Demo loads the frozen threshold.
- [ ] Demo displays a risk probability.
- [ ] Demo displays the classification using the frozen threshold.
- [ ] A reproducible test applicant/example can be demonstrated.
- [ ] UI clearly identifies the model and threshold used.

## Out of scope
Complex frontend, cloud deployment, additional model tuning, and post-test optimization.
