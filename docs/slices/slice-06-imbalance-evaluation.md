# Slice 06 — Imbalance Evaluation

## Module
`evaluate`

## What to build
Evaluate models with metrics appropriate for an imbalanced binary classification problem.

## Acceptance criteria
- [ ] ROC-AUC is reported.
- [ ] PR-AUC is reported.
- [ ] Precision, recall, and F1 are reported.
- [ ] Confusion matrix is generated.
- [ ] Accuracy is not the sole selection metric.
- [ ] Results are saved reproducibly.

## Out of scope
SMOTE unless explicitly added as a time-permitting experiment.
