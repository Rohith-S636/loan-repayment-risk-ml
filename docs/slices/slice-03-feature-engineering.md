# Slice 03 — Feature Engineering

## Module
`feature_engineering`

## What to build
Create a compact set of domain-driven financial and repayment features.

## Acceptance criteria
- [ ] Valid application financial ratios are created.
- [ ] Bureau credit/debt/overdue aggregates exist.
- [ ] Previous-application approval/refusal aggregates exist.
- [ ] POS/CASH delinquency statistics exist.
- [ ] Installment payment/delay statistics exist.
- [ ] Credit-card balance/delinquency statistics exist.
- [ ] Invalid divisions are handled safely.

## Out of scope
Polynomial expansion and large automatic feature generation.
