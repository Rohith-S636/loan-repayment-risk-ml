# Slice 08 — Final Evaluation

## Module
`evaluate`

## What to build
Freeze the selected threshold and produce final test-set metrics and figures.

## Acceptance criteria
- [ ] Final test predictions use the selected model/pipeline.
- [ ] ROC-AUC and PR-AUC are recorded.
- [ ] Precision, recall, F1, and confusion matrix are recorded at the selected threshold.
- [ ] Final figures are saved.
- [ ] Validation tuning and final test evaluation are clearly separated.

## Out of scope
Further tuning after inspecting test results.
